# 15 种风格 · 60 秒演示

本工程为原创几何练习，用于比较风格的形态、材料与动作语言，不包含科学论断。画幅 1920 × 1080，30 fps，每种风格展示 4 秒。

风格分类参考 [Vincentwei1021/mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)。没有复制该仓库的品牌、剧情、源码、照片、音频或字体；复用本项目 `/engine/` 与已列明许可的共享字体。来源边界见 [NOTICE.md](../../NOTICE.md)。

| 时间 | 风格 id | 主体与可观察的动作 | 实现边界 |
| --- | --- | --- | --- |
| 0–4 | `cel-boil` | 笑脸轻跳，按风格帧率重绘轮廓 | 扰动按时间帧号与固定种子计算 |
| 4–8 | `isometric` | 四座等距块体逐个生长 | 固定 2.5D 投影与绘制顺序 |
| 8–12 | `flat-vector` | 圆、圆角矩形与三角构成对照 | 实色 Canvas 几何 |
| 12–16 | `line-art` | 线条依路径描出房屋和太阳 | 折线点列生长 |
| 16–20 | `3d-render` | 旋转方块、面着色与落地阴影 | Canvas 投影示意，非 Blender 或真实光照 |
| 20–24 | `morph` | 圆的对应点连续变成方形 | 固定点对应的轮廓插值 |
| 24–28 | `sticker` | 白边卡片出现，结构标签靠近主体 | 程序绘制贴纸，无外部图像 |
| 28–32 | `hud` | 网格、环形刻度与状态圆弧出现 | 73% 明确标记为示意，不是真实测量 |
| 32–36 | `collage` | 两张不规则纸片层叠重组 | 程序绘制纸边与胶带 |
| 36–40 | `aurora-glass` | 柔色场下的半透明面板出现 | 渐变与透明度示意，非真实折射 |
| 40–44 | `bauhaus` | 基础形构成强秩序版面 | 有限色板与几何布局 |
| 44–48 | `synthwave` | 条带落日、山峰与透视网格 | 扫描感仅在主体区域，不覆盖字幕 |
| 48–52 | `pixel` | 20 px 像素笑脸离散跳跃 | 整数网格，关闭主体模糊与辉光 |
| 52–56 | `liquid` | 两团柔软形态靠拢并形成流动轮廓 | 参数化边界示意，非流体模拟 |
| 56–60 | `variety` | 笑脸反应，“原来如此”逐字短促弹入 | 横屏适配，连续解释字幕独立保持稳定 |

每段首帧展示编号、中文名称、英文名和 id；主体占中央，原理说明在 y=815，连续字幕放在 y=944 并在辉光后绘制。完整阅读停留从短淡入结束后计，每段解释字幕约 3.6 秒。

## 验收

```bash
python engine/render.py examples/style_gallery --sheet 2 6 10 14 18 22 26 30 34 38 42 46 50 54 58
python engine/render.py examples/style_gallery --det
python engine/render.py examples/style_gallery --clip 0 8 preview
```

检查每种风格的稳定主体、文字对比、字幕最长句、确定性和段间硬切。风格演示不等于成片模板；新主题应自行决定对象、事实、分镜和阅读停留。

实际检查结果由执行者记录；完整视频导出依用户要求执行。
