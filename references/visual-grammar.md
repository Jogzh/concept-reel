# 画面语法速查

先读 [visualization.md](visualization.md) 确定解释对象和方法，再用这份速查安排版式、标注与动效。这里的示例为通用教学设计，不来自第三方短片分镜。

## 一、按信息关系选择表达

| 句子在表达什么 | 可以怎样画 | 原创示例 |
|---|---|---|
| 数量或比例 | 计数、刻度、同尺度长度 | 到达与完成计数并排 |
| 时间变化 | 时间轴、轨迹、折线 | 显示每秒队列长度 |
| 状态转移 | 对象跨区移动，保留编号 | 任务从等待区进入完成区 |
| 操作步骤 | 当前步骤亮起，中间结果保留 | 逐步检查一组输入条件 |
| 对照 | 相同基线下同时展示 | 两种处理能力接受相同输入 |
| 空间包含 | 局部放大与定位锚点 | 从整体结构推进一个部件 |
| 连接与传播 | 节点、边和明确方向 | 一次变化沿指定路径传递 |
| 定义或公式 | 将符号贴回已有例子 | 未完成量=累计到达−累计完成 |

遇到不能直接表示的概念，先解释图形的含义。抽象图表依靠标注、轴和图例也可以讲清楚，不必强行画成实物。

## 二、一屏的注意力分配

突出当前要比较或追踪的对象。辅助信息降低强调，必要来源保持可读。主体、字幕与常驻信息的区域只是构图起点，具体边界见 [layout.md](layout.md)。

稳定画面适合比较，局部高亮适合引导当前步骤。不要为了每句字幕都“有动作”而移动正在被阅读的标注。

## 三、常驻元素应提供信息

计数器、章节标记、时间轴和仪表可以帮助观众定位。使用前回答：它量什么？单位是什么？何时更新？它与当前镜头有什么关系？

仪表表示模型量时注明“示意”或模型含义，不把主观程度画成未经测量的精确读数。当前镜头不需要的常驻元素可以退场。

## 四、颜色与其他编码保持一致

颜色可以表示类别、状态或强调。全片固定一个含义，并同时提供文字、形状或编号，避免只靠颜色区分结果。

例如，队列示意可以将未完成任务使用蓝色、完成任务使用金色，并保留对应区名。错误或警告可以另设红色，但不要让相同红色同时表示多个相互冲突的意思。

数据比较应使用相同的长度、面积或位置尺度。面积图形需要按面积比例设置大小，不能直接将数值当成半径。

## 五、镜头之间怎样连接

| 接法 | 适合的语义 | 要检查的问题 |
|---|---|---|
| 硬切 | 明确切换条件、位置或观察对象 | 两边身份和条件是否标清 |
| 溶解 | 平滑退出和进入 | 重叠期间是否难以读图 |
| 变形 | 同一对象的状态变化 | 对象身份是否可追踪 |
| 推近或拉远 | 整体与局部、不同尺度 | 是否保留定位锚点，比例是否说明 |
| 压暗或闪光 | 暂停、重点揭示或章节分隔 | 强度是否妨碍观看和阅读 |
| 同屏换内容 | 保留版式与共同基线 | 上一个结果是否仍需用于比较 |

转场时长由内容和播放效果决定。章节内可以沿用相同版式，整片也可以有明确的硬切。

## 六、动效应暴露状态

- 位置变化表达路径或转移，不承担无关的装饰运动。
- 数值从数据或模拟中计算，动画中的中间值也应有明确含义。
- 线条生长可以展示顺序，完整关系需要同时可见时直接保留整图。
- 文字进入效果尽量短，给稳定阅读留出时间。
- 随机位置与粒子路径固定种子，任意`seek(t)`得到相同结果。
- 辉光、阴影和噪点控制在不遮蔽边缘与标注的程度。

## 七、把语法落进分镜

| 时间 | 理解目标 | 对象与动作 | 标注 | 声音 |
|---|---|---|---|---|
| 0–4 | 认识任务的路径 | 一张编号卡从输入区经过窗口到完成区 | 到达、处理、完成 | 可选一次提示 |
| 4–10 | 比较输入输出 | 更多卡片到达，窗口按固定能力完成 | 个/秒 | 可选统一节拍 |
| 10–16 | 解释积压 | 未完成卡片保留，计数上升 | 当前未完成 | 留空 |

检查对象含义、数据一致性、阅读停留与转场连续性。实际渲染命令见 [engine.md](engine.md)，逐图修改方法见 [visualization.md](visualization.md) 第八节。
