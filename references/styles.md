# 15 种动态风格与 AI 选型

风格扩大画面的可能性，内容决定选哪一种。先读 [制作规范](../docs/production-guide.md)，明确观众要理解的关系，再选择造型、材质、运动与文字语言。风格不能替代事实、分镜或可读性检查。

本目录参考 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15) 公开的 15 类风格与 signature features，重新编写适合 Concept Reel 的内容用途和 Canvas 实现建议；参考版本为 `49052d80bfaf9fa8412cc9710530e5e95a3b8d8c`。不复用原成片品牌、文案或剧情。来源与材料边界见 [NOTICE.md](../NOTICE.md)。

## 从内容选风格

按以下维度提出 2–3 个候选，并说明每个候选会怎样帮助观众理解；不要只给出风格名称。

| 要判断的维度 | 可以探索的方向 |
| --- | --- |
| 解释关系 | 步骤与因果用可追踪对象；结构与空间用等轴；连续变化用形变或液态；数量与对照用贴纸、扁平或线条。 |
| 主体是什么 | 真实物体需要轮廓和结构线索；抽象量可用几何、数据图表和符号；情绪重点可用花字或手绘动作。 |
| 信息密度 | 贴纸和 HUD 可容纳多层标注；线条、玻璃、3D 质感适合少量大主体。密度高时延长观察时间。 |
| 运动语气 | 手绘、像素、拼贴用阶梯节奏；扁平、花字用弹性；包豪斯用机械精确；玻璃用缓慢漂移。 |
| 色彩与材质 | 纯色、纸感、细线、荧光、半透明、像素、实体着色分别改变画面语气。文字与语义色优先于装饰。 |
| 实现成本 | 线条、扁平和几何适合直接绘制；照片贴纸需可用素材；复杂液态、真实 3D、玻璃折射需要额外实现和验证。 |

在 `storyboard.md` 记录：主风格、选用原因、至少两个可辨认的风格特征、需要自定义的动作、实际实现边界。用户已有风格要求时优先遵循。

可选择一个主风格与一个辅助风格。主风格统一字体、色彩含义、空间和运动；辅助风格解决某一类表达需求，例如“贴纸科普 + 等轴”解释部件空间关系，“线条 + 形变”展示连续过程，“扁平 + 手绘”强调一次意外，“像素 + 花字”突出短情绪词。混合应有明确任务，避免在同一时刻叠加多个强烈纹理、节奏或焦点。

## 工具入口与实现层

风格 ID、机器可读的参数和实际预设以 [engine/styles.json](../engine/styles.json) 为单一数据源。本文给出创作建议；生成器输出的 `--describe-style` 说明可用默认值，不保证特定内容已经完成。

```bash
python scripts/new_film.py --list-styles
python scripts/new_film.py --list-styles --json
python scripts/new_film.py --describe-style isometric
python scripts/new_film.py --describe-style isometric --json
python scripts/new_film.py projects/my_film --style isometric --title "片名" --duration 60
```

新工程写入风格预设与场景空骨架。`VStyles.apply` 应用预设，`VStyles.caption` 绘制相应文字样式，`VStyles.demo(fr, profile, t)` 展示风格能力。具体调用参数见 [引擎 API](engine.md)，保留的 B/C 起始外观见 [worlds.md](worlds.md)。

画廊 demo 是各类风格代表动作的的能力样本，不是完整工程模板，也不是新片的固定分镜。选择风格后仍需填写字幕、事实、场景与动作；改变背景色不会自动完成一种风格。当前画幅固定为 1920×1080 横屏。

## 风格目录

### `cel-boil` · 逐帧手绘 / 线条沸腾

**识别特征：** 少量暖色、纸纹、略微错位的填色，线条按固定帧节奏切换微差版本；快动作可用一帧拉长轮廓，烟团、星芒与速度线有手绘节奏。

**内容用途与构图：** 适合生活机制、角色反应、尝试与失败、自然现象中的直观动作。让一个可辨认主体占据画面重心，手绘辅助符号跟随关键变化，留出字幕与落点空间。

**动作与参数：** 主体可在 24fps 下每两帧更新，静止状态每三帧更新，快速动作逐帧更新；3–4 组轮廓微差循环，纸纹透明度约 10–15%。用预备动作、挤压拉伸、余势表达力与情绪。

**实现边界：** Canvas 可用固定种子的路径扰动与时间量化模拟 boil；这不等于逐张人工手绘。扰动应保持对象身份、重要文字和图表稳定，不能用随机抖动掩盖动作缺失。

### `isometric` · 等轴 2.5D

**识别特征：** 无透视灭点的等轴投影、清楚的顶面与侧面、微缩物体、分层阴影与平行运镜。

**内容用途与构图：** 适合系统结构、城市与工厂流程、资源运输、服务器和空间分工。先给整体，再局部展开；对照对象共享尺度和投影，标签保持屏幕平面可读。

**动作与参数：** 物体沿统一投影网格移动，按深度排序；建造先落底面，再拉起立面，顶面可延迟 2–3 帧；前中后景平移速度可用 1∶0.8∶0.6 建立层次。真实等轴与 2∶1 游戏式投影择一使用，避免混用。

**实现边界：** Canvas 用投影函数与多边形面表达 2.5D，遮挡排序需要单独处理。它没有真实三维相机、光照或碰撞；旋转复杂物体时须补足面与排序逻辑。

### `flat-vector` · 扁平矢量

**识别特征：** 纯色色块、几何化角色与物体、干净留白、少量清晰描边，元素入退场带弹性。

**内容用途与构图：** 适合入门科普、产品机制、步骤、行为与条件对照。用可辨认轮廓和统一图形语法，让色块划分叙事区域；同一时刻只让一个主体承担主要动作。

**动作与参数：** 预备、冲出、回弹构成一次入场；次要元素错开 2–4 帧，移动时约 10% 挤压拉伸；色块扩大或可追踪对象穿过画面可以承载转场。

**实现边界：** 几何图形、路径与角色关节可直接绘制，但角色 rig、表情与场景仍需按内容实现。避免仅用弹出卡片代替观众需要看到的过程。

### `line-art` · 线条动画

**识别特征：** 单色或双色、等宽细线、大面积负空间、轮廓逐段描出，上一段线延伸为下一段关系。

**内容用途与构图：** 适合路径、连接、结构图、建筑轮廓与简洁过程。用线的生长顺序明确阅读顺序；复杂图可保留稳定锚点，让新增线指向下一观察位置。

**动作与参数：** 全片统一线宽，1920×1080 下约 2–4px 可作为起点；控制描绘进度而非逐帧累积路径。拐角稍慢，绘完保持，必要时从相同轮廓填入色面。

**实现边界：** 细线需要原尺寸与小尺寸检查，信息线和装饰线需有层级。连续一笔叙事需要设计相容路径，预设不会自动连接任意复杂物体。

### `3d-render` · 实体质感 / 3D 渲染适配

**识别特征：** 体积、软阴影、方向光、高光与明暗面，少量实体作为中心，阵列与缓慢收尾的动作强调材质。

**内容用途与构图：** 适合展示实体形状、容器、颗粒、聚集与排列；主体少而大，固定光向和空间关系，为轮廓和标签保留对比。

**动作与参数：** 程序化投影配合渐变着色、接触阴影和高光；阵列的延迟由位置或编号计算。位移可先快后慢，落地挤压与余势使用明确时间函数。

**实现边界：** 当前是 Canvas 程序化着色与投影适配，不是 Blender/Cycles 或真实 PBR 渲染，不承诺真实玻璃折射、软体物理、布料与景深。需要这些效果时须另建可验证的渲染路线，不能把二维高光称作真实 3D。

### `morph` · 形变动画

**识别特征：** 轮廓连续变化、简形作为桥梁、变形伴随轻微位移与旋转，起止对象都能被认出。

**内容用途与构图：** 适合变化、分类、抽象关系、同一对象的不同状态与尺度。保留编号、颜色或中心锚点，让观众理解变化的是哪个对象；语义对照需要同时可见时改用并排布局。

**动作与参数：** 对齐路径顶点数与起点；复杂轮廓可以 A→圆/胶囊→B，每段约 8–12 帧作为起点，起止各留缓冲；约 10–15% 挤压拉伸帮助形成自然节奏。

**实现边界：** 内置规则形状可直接插值，任意 SVG 轮廓需要重采样和顶点匹配。形变只是图形叙事，不能暗示没有事实依据的物理转化或因果关系。

### `sticker` · 粗描边贴纸科普

**识别特征：** 贴纸边缘、克制的冷静底色、对象与精确图表共处大画布，通过平移和缩放串联信息点。

**内容用途与构图：** 适合部件拆解、机制讲解、跨尺度比较与财经数据。把大画布组织为问题、证据与结论区，镜头运动帮助定位，数值和单位有稳定落点。

**动作与参数：** 剪影可加约 8–12px 白边；图表生长、计数与描线来自同一份数据。平移与缩放有较长缓动，落到新信息后停住，避免快速语速式包装压缩阅读时间。

**实现边界：** Canvas 可画程序化对象并加贴纸边缘；照片贴纸需要可使用的图片、抠图和来源记录，预设不自带照片库。大画布运镜与实际图表仍需按分镜编写。

### `hud` · 赛博 HUD / 科幻界面

**识别特征：** 青橙线框、目标括号与准星、环形扫描、等宽数据、网格和受控辉光。

**内容用途与构图：** 适合传感器、监测流程、算法状态、设备结构与反馈循环。中央主体和外围读数分工，主数据显著高于装饰小字，标注连接真实解释对象。

**动作与参数：** 线框按层级展开；雷达角度由时间计算；括号从约 1.4 倍收缩到目标，数据可短暂扰动后落定。扫描线和辉光只作低强度辅助。

**实现边界：** 展示值须来自数据或明确标注为示意，固定随机装饰不能冒充实际指标。小字、扫描与循环运动容易争抢焦点，稳定阅读时可降亮度或停止。

### `collage` · 拼贴剪贴

**识别特征：** 纸片和剪影边缘、半调网点、胶带或手写标记、比例夸张的拼装，定格般的阶梯运动。

**内容用途与构图：** 适合历史材料、媒体信息、观点碰撞、超现实类比与带编辑感的解释。纸层承担分组，证据材料与装饰明确区分；夸张比例保持解释对象可辨认。

**动作与参数：** 主体可按 6–12fps 更新，位置偏差约 ±2px；分段关节围绕固定锚点旋转，替换帧表现嘴部与表情。拍入、揭开、翻页等动作连接纸层。

**实现边界：** 程序化纸片与网点不等于照片拼贴。使用照片、报刊或手写素材须记录来源与权利；不自动附带抠图、人物 puppet 或页面翻折模拟。

### `aurora-glass` · 弥散渐变 / 玻璃拟态

**识别特征：** 邻近色的大光斑缓慢漂移、半透明圆角面、高光边缘与细微噪点，信息量较低。

**内容用途与构图：** 适合少量概念、层级、柔和连接与产品状态。用一到两个玻璃面承载主体信息，背景光斑避开正文，重要图表需要独立对比度。

**动作与参数：** 参考光斑数量 3–5、模糊 80–150px、20–40 秒长周期；面板可用约 5–10% 白填充与细高光。漂移用平滑正弦或长曲线，文字用透明度与小位移进入。

**实现边界：** Canvas 渐变与半透明面是视觉近似，真实背景模糊和折射需要离屏采样或 shader。不要把辉光当作玻璃材质；亮背景下须实测正文对比。

### `bauhaus` · 几何构成 / 包豪斯

**识别特征：** 圆、三角和矩形、限定原色与黑白、模块网格、精确落点和几何中心旋转。

**内容用途与构图：** 适合比例、分组、排列、数量关系与规则系统。网格是关系的尺子，用大小、位置和数目传递信息；造型简洁时增加文字标签避免歧义。

**动作与参数：** 位移为网格模数的整数倍；旋转围绕中心、边缘顶点或整体中心。用克制的 easeInOutQuad 或机械匀速，落点不弹跳；节拍由明确 cue 驱动。

**实现边界：** 基础几何可直接实现，复杂动态图案需要自行编排。节拍服务知识阅读，不能强行要求每拍新增信息或把真实物体简化到无法认出。

### `synthwave` · 80s 霓虹 / VHS / Y2K

**识别特征：** 霓虹地平线和透视网格、日落色带、镀铬般文字、低强度扫描线与色偏；Y2K 可加入拟物窗口与酸性色。

**内容用途与构图：** 适合数字媒介、年代线索、游戏与复古技术主题。选择一个年代语汇作为主线，地平线定位主体，装饰窗口不抢占信息区。

**动作与参数：** 网格滚动由解析投影计算，紧高光和散辉光分层；VHS 可轻微 RGB 偏移 1–2px、少量扫描线或固定时刻故障帧。Y2K 窗口出现、拖拽、点击承担界面叙事。

**实现边界：** VHS 做旧要可关闭，公式、数字和正文保持稳定。年代引用不等于把所有霓虹、故障、镀铬和窗口效果同时堆叠；Canvas 近似色偏不自动完成真实通道后处理。

### `pixel` · 像素 / 8-bit

**识别特征：** 低分辨率硬边缘、有限色板、阶梯运动、精灵帧与可选抖色。

**内容用途与构图：** 适合离散状态、网格规则、计数、游戏机制与分步模拟。保持整像素坐标和统一像素尺度，重要数据与字幕可以使用独立清晰文字层。

**动作与参数：** 可用 320×180 内部分辨率整数放大至横屏，最近邻缩放；色板约 8–32 色，精灵约 8–12fps。多层背景按整数位置滚动，帧索引由时间决定。

**实现边界：** 需实际绘制像素造型或精灵，普通矢量图加马赛克不能替代像素设计。低分辨率会损失文字与细图表信息，CRT 等滤镜应按阅读结果决定。

### `liquid` · 液态流动

**识别特征：** 有机曲线、液滴与拉丝、聚合融合、波浪前沿，次级小滴跟随主动作。

**内容用途与构图：** 适合汇聚、扩散、流动和状态切换的直观示意。先明确守恒量与对象边界，再决定是液滴、连续流还是仅作为转场；保留起止状态让变化可理解。

**动作与参数：** 波浪前沿可含 3–5 个错相凸起；次级液滴晚 2–3 帧，断裂后短暂回弹；采用前快后慢的甩出节奏。融合可用 metaball 场或离屏模糊加阈值实现。

**实现边界：** Canvas 曲线、桥接形状和渐变可提供液态视觉适配；它们不是流体求解、真实黏度或自动 metaball shader。物理量与运动关系需另行计算，不能靠装饰流动证明机制。

### `variety` · 综艺花字

**识别特征：** 胖体文字、多层白边和彩色外边、投影、弹性 pop，爆炸框、汗滴、问号与闪光表达情绪。

**内容用途与构图：** 适合短问题、意外、强调与角色反馈。花字靠近其解释对象，作为瞬时重点；正文字幕保持稳定，术语和长结论另用清晰排版。

**动作与参数：** 入场可在约 8 帧内完成 0→1.15→1.0，逐字错开约 2 帧；情绪词配对应装饰和落点音，驻留轻微摆动即可。层叠描边应先外后内绘制。

**实现边界：** 当前为横屏 Canvas 花字适配，不承诺参考原片的竖屏、vlog 实拍或语音识别同步。完整阅读时间从文字显现后计算，不让连环弹跳影响读词。

## 扩展与验收

把候选风格落实为“主体怎样画、变化怎样发生、文字怎样读”的具体决定。允许更换色板、调整节奏、添加自定义组件；必须保留足够的识别特征与语义一致性。新增风格参数统一进入 `engine/styles.json`，相关绘制能力与生成器说明同时更新。

先制作代表风格且最难解释的一镜，运行 `--stills` 与 `--motion`，检查主体、材质、起止状态和阅读；再运行 `--det` 验证乱序 seek。颗粒、boil、故障帧、精灵、液滴和阵列均从时间与固定输入计算。画廊验证不能替代新工程的真实关键帧、转场与数据核对。

参考仓库对 15 种风格提出了不同技术路线，包含 SVG、Canvas、WebGL、Three.js 和 Blender。本项目的统一 Canvas 预设是可继续编程的起点；需要高阶能力时应说明使用的真实路线、依赖与验证结果，再按交付范围推进。
