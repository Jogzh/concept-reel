# 外观与默认参数

新工程支持 [15 种独立动态设计风格](styles.md)，并保留 **C 夜曲** 和 **B 寓言** 兼容入口。这份文档说明 B/C 与已有组件的默认值，供修改旧工程时参考。组件的来源与许可说明见 [NOTICE.md](../NOTICE.md)。

外观不规定主题的讲法。角色、实验、图表、转场和时间表应按分镜选择，不需要照搬任何现有短片。

## 选择外观

| 外观 | 适合的画面需求 | 对应设置 |
|---|---|---|
| B 寓言 | 场景、角色、卡片和较大色块 | `--world B`，theme为flat |
| C 夜曲 | 图表、文字、路径和深色背景 | `--world C`，theme为night |

同一工程可以按镜头调整背景、色板和辉光。若切换外观，保留对象身份、颜色语义和文字可读性。

新风格通过 `--style ID` 创建，使用 `VStyles` 与 `engine/styles.json`，不受这里 B/C 色板或字幕布局限制。`--style` 与 `--world` 互斥；没有指定时默认 C。

## 共用设置

画布固定1920×1080。新工程默认30fps，可通过`--fps`修改。左右与上下留白按播放设备和主体范围设置，底部字幕附近预留空间，具体检查见 [layout.md](layout.md)。

字体使用Noto Serif SC、Noto Sans SC、Cormorant Garamond、Lora、JetBrains Mono和Courier Prime。字体来源与SIL OFL许可证保留在`engine/fonts/`。通过`get_fonts.py`补齐后，页面加载阶段统一等待字体。

主体默认经过辉光和颗粒合成。实心对象可以画入`fr.look.under`，或降低`fr.look.bloom`，避免局部过曝。

## B 寓言

背景由当前镜头绘制，可以使用远景、角色和前景分层。`flat`背景提供一张底色，不自动生成插画或角色。

| 参数 | 当前默认值 |
|---|---|
| 主体与字幕色 | `#FFFAEB` |
| 金色 | `#EEC672` |
| 红色 | `#FC593F` |
| 纸色 | `#D4CABA` |
| 辉光 | .12 |
| 字幕字体 | Noto Sans SC，700字重 |
| 字幕字号与中线 | 48px，y=966 |
| 字距 | 字号的.07倍 |
| 字幕进入 | 逐字亮起，字间错开最长.07s |

`K.gauge`可以显示有单位或定义清楚的模型量。传入自己的`label`、`caption`、`max`与`redFrom`，不要把默认仪表含义当成所有主题的讲解规则。

场景颜色由对象和信息层级决定，不必使用固定地点配色。片名可以调用`K.titleGilt`，也可以自行绘制；角色与母题由新片的内容选择。

## C 夜曲

背景是深色场、星点与暗角。默认值适合细线和发光文字，复杂实体场景可以调整背景与辉光。

| 参数 | 当前默认值 |
|---|---|
| 背景底色与中央色 | `#010104`、`#0B1830` |
| 主体字色 | `#F8F9F8` |
| 字幕与英文 | `#D9D9D8`、`#86898C` |
| 金色 | `#F8D893` |
| 冰蓝 | `#64E3F6` |
| 玫红 | `#E84B75` |
| 辉光 | 1 |
| 中文字幕 | Noto Serif SC 400，41px，y=939 |
| 英文字幕 | Lora Italic，29px，y=995 |
| 中文字距 | 字号的.12倍 |
| 字幕进入 | 整行.55s淡入，英文晚.18s |

`K.chapterMark`提供章节号与文字。`K.titleNight`提供点阵片名。星点和彗尾光点可以辅助空间定位或作为装饰，具体机制仍需要由对象、关系和数据来解释。

双语字幕应在受众需要时使用；翻译、读图和阅读时间都需要复查。C外观不要求每章闪光、压暗，也不要求每个动作登记音效。

## 保留的gilt组件

`gilt`背景、色板、字幕和年份栏为兼容上游工程保留，生成器不把它列为独立新建选项。

| 参数 | 当前默认值 |
|---|---|
| 主体色与金色 | `#E8E3D9`、`#DDBD74` |
| 红色 | `#D9583C` |
| 辉光 | .34 |
| 字幕 | Noto Serif SC 700，54px，y=915 |
| 字距 | 字号的.11倍 |
| 背景控制 | warm/pool/floor/horizon/dust |

年份栏仅在时间或历史来源对解释有意义时使用。场景从暖到冷、片名卡和转场顺序都由分镜决定。

## 声音与验证

`audio.py`支持合成事件音和已有配乐。无BGM时合成低频背景；BGM使用`--bgm FILE --bgm-db DB`。声音不依赖所选外观，音效应服务于观察与节奏。

参数修改后，检查最长字幕、最大对象和最亮背景下的静帧，再检查转场序列和`--det`。默认值不能保证每个主题在每种播放尺寸下都清楚。

可运行的上游示例包括 [fold_C](../examples/fold_C/film.js)、[pigeon_B](../examples/pigeon_B/film.js) 和 [kit_gallery](../examples/kit_gallery/film.js)。来源与改动范围见 [NOTICE.md](../NOTICE.md)。
